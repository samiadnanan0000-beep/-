# وافي - دفتر الديون والذهب (Wafi)

تطبيق مالي لإدارة الديون والالتزامات المالية والذهب والمعادن الثمينة بنمط العمل الكامل دون إنترنت (Offline-First)، مستوحى من لغة تصميم Samsung One UI 8 مع دمج Google Play Billing للشراء الدائم وإعلانات الفتح AdMob المشروطة.

### User Review & Critical Decisions

> [!IMPORTANT]
> تم تأكيد خيارات التخصيص الأساسية بناءً على إجاباتك في المرحلة الأولى:
> - **العملة الأساسية الافتراضية**: شاشة تهيئة ترحيبية ناعمة عند أول تشغيل لاختيار العملة الأساسية (ريال يمني، ريال سعودي، دولار أمريكي، ذهب عيار 21) مع دعم التبديل بين العملات والأصناف بسلاسة في أي وقت.
> - **نظام الأمان والقفل**: الأمان اختياري ومعطل افتراضياً عند التثبيت الأولي لتجربة مستخدم سريعة، مع إمكانية تفعيل القفل بالبصمة (Biometric) أو رمز PIN السري من شاشة الإعدادات.
> - **النسخة الخالصة مدى الحياة**: دعم `wafi_remove_ads_lifetime` عبر Google Play Billing Client مع التحقق والتأكيد التلقائي، وميزة "استعادة المشتريات" بضغطة زر.

---

### 1. Overview & Core Concept

- **طبيعة التطبيق**: دفتر حسابات ذكي متكامل للمتاجر، الأفراد، وتجار الذهب، يسجل ديون "لك" (مدين/عليه) و"عليك" (دائن/له)، مع سجل تفصيلي لكل شخص وإجمالي الموقف المالي.
- **الجمهور المستهدف**: أصحاب المحلات، رواد الأعمال، وتجار الذهب والمجوهرات، والأفراد الباحثين عن تطبيق دقيق وخاص بنسبة 100% بدون اشتراكات أو خوادم خارجية.
- **القيمة الجوهرية**: سرعة فائقة بنمط Offline-First مع قاعدة بيانات Room محلية، وحماية أمنية للبيانات، ونسخ احتياطي واستعادة بضغطة واحدة، وتصميم One UI 8 مريح للإبهام وذو هوية عربية أصيلة.

---

### 2. User Experience & Visual Design (Samsung One UI 8)

- **الهوية البصرية والألوان**:
  - تصميم كبسولي ناعم ومريح مع زوايا منحنية واسعة (`26.dp`).
  - ألوان One UI 8 الحيوية: خلفية رمادية فاتحة ناعمة (`#F8F9FA` / `#121212` للوضع الليلي)، كبسولات بيضاء مرتفعة بظلال خفيفة، أزرق سامسونج المميز (`#0C66E4`)، أحمر مرجاني دافئ لـ "عليه/لك" (`#E5484D`)، وأخضر زيتوني زمردي لـ "له/عليك" (`#30A46C`)، ولمسات ذهبية رصينة للأصناف والذهب (`#E5A93C`).
- **أهم تدفقات المستخدم**:
  1. **الترويسة العلوية One UI الكبيرة القابلة للطي**:
     - شريط علوي قابل للتمدد والانكماش مع التمرير.
     - بطاقة كبسولية عريضة للموقف المالي العام: [عليك: X | لك: Y | الصافي].
     - شريط الترقية الذهبي الكبسولي (يختفي فور شراء النسخة الخالصة).
  2. **قائمة جهات التعامل المجمعة (Grouped Cards)**:
     - بطاقات الأشخاص مع شارات إحصائية (عدد الحركات، تاريخ آخر حركة، والمبلغ الحالي بسهم ملون).
     - زر سريع `(+)` لكل بطاقة لإضافة معاملة فورية للشخص.
  3. **شاشة كشف حساب الشخص (Person Statement)**:
     - بطاقة ملف الشخص مع أزرار الإجراءات السريعة: اتصال هاتفي مباشر، رسالة واتساب منسقة بنص المطالبة المالية، وتصدير كشف حساب PDF رسمي يحمل شعار وعلامة مائية لتطبيق وافي.
     - جدول كشف الحساب التراكمي (الرصيد بعد كل حركة).
     - **احتفالية تصفير الحساب**: عند بلوغ الرصيد `0.0` تنطلق قصاصات ملونة احتفالية (Confetti Canvas) وتظهر بطاقة "حسابك وافي ومصفى ✨".
  4. **شاشة إضافة حركة مالية / ذهب (Add Transaction)**:
     - حقل بحث واقتراح الأسماء الذكي.
     - شريط تبديل كبسولي: [محلي | دولار | سعودي | ذهب عيار 21 | فضة].
     - حقل المبلغ مزود بآلة حاسبة منبثقة One UI مدمجة لسهولة الحساب دون مغادرة الشاشة.
     - زران عريضان في متناول الإبهام بالأسفل: أحمر مرجاني "عليه" وأخضر زيتوني "له".
  5. **لوحة الإعدادات والأمان**:
     - قسم الشراء والاستعادة لـ `wafi_remove_ads_lifetime`.
     - قسم الأمان: تفعيل البصمة Biometric أو رمز PIN.
     - قسم سقوف الائتمان (Credit Ceilings) مع تنبيهات بصرية حمراء فورية.
     - قسم النسخ الاحتياطي التلقائي وزر فحص واستعادة النسخ الاحتياطية من الهاتف.

### 3. Key Product Decisions & Trade-Offs

- **Google Play Billing Client**:
  - *القرار*: استخدام مكتبة `billing-ktx:6.1.0` الرسمية لتنفيذ منتج غير قابل للاستهلاك `wafi_remove_ads_lifetime` مع التأكيد الأمني `acknowledgePurchase`، وميزة استعادة المشتريات `queryPurchasesAsync`.
  - *الميزة*: الامتثال الكامل لسياسات Google Play مع حفظ دائم في إعدادات التطبيق لإخفاء الإعلانات والترقيات فوراً.
- **إعلانات AdMob App Open المشروطة**:
  - *القرار*: فحص حالة الشراء أولاً (`isAdsRemoved == true`)، وإذا كان الشراء مفعلاً يتم إلغاء الإعلانات بالكامل. في حالة الحساب العادي، يتم تطبيق تقييد تكرار (Frequency Capping: Cold Start أو مضي 4 ساعات).
- **قاعدة بيانات Room المحلية النمطية**:
  - *القرار*: جداول محكمة لـ `Person` و `TransactionRecord` و `UserSettings` لضمان أداء فوري دون الحاجة إلى إنترنت، مع حساب الرصيد التراكمي وتعدد العملات والذهب بالغرام.
- **النسخ الاحتياطي والاستعادة الذاتية**:
  - *القرار*: تصدير واستيراد بصيغة JSON آمنة ومحمية في مجلد المستندات بالهاتف، لتسهيل النقل واسترجاع البيانات بضغطة زر واحدة حتى بعد تغيير الجهاز.

#### خطة التنفيذ البرمجية المباشرة بعد الاعتماد:
1. تحديث `metadata.json` واسم التطبيق في `res/values/strings.xml` إلى "وافي - دفتر الديون والذهب".
2. تحديث التبعيات في `build.gradle.kts` لإضافة `play-billing-ktx` و `play-services-ads` مع تهيئة Room.
3. إنشاء طبقة البيانات (Room Database, Entities, DAO, Repository).
4. إنشاء مديري الخدمات: `BillingManager` للشراء والاستعادة، `AppOpenAdManager` لإعلانات الفتح مع تقييد التكرار، `SecurityManager`، و `BackupRestoreManager`.
5. بناء واجهات One UI 8 المتقنة بأسلوب كبسولي فخم ومتجاوب مع الوضعين الفاتح والداكن.
6. التحقق النهائي من البناء والتجميع بنجاح عبر `compile_applet`.
